================================================================================
  RESPONSIVE BEHAVIOR
================================================================================

Desktop (> 768px):
- Panel width: 450px fixed
- Slides in from right
- Status messages positioned left of panel

Mobile (< 768px):
- Panel width: 100vw (full screen)
- Slides in from right edge
- Status messages hidden when panel open
- Touch-friendly button sizes


================================================================================
  ANIMATION EFFECTS
================================================================================

Panel Open:
  - Slide-in animation (0.3s ease-in-out)
  - Panel translates from right: -450px → 0px

Panel Close:
  - Slide-out animation (0.3s ease-in-out)
  - Panel translates to right: 0px → -450px

Health Dot:
  - Pulse animation (2s infinite)
  - Opacity: 1 → 0.6 → 1
  - Scale: 1 → 0.9 → 1

Status Message:
  - Fade-in: opacity 0 → 1, translateX(20px) → 0
  - Duration: 0.3s
  - Auto-dismiss after 5 seconds
  - Fade-out: 0.3s

Button Hover:
  - Background color change (0.1s)
  - Slight scale transform
  - Shadow effect
